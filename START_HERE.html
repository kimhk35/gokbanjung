닉네임 게스트 · 관리자 로그인 승인 · 추천 질문/토론 · 공식 경전 · 일/주/월 퀴즈와 보상 · 큰 글씨를 포함합니다.

기존 사이트 업데이트 순서

  1. 기존 폴더를 백업하고 ZIP 안의 gospel-class 전체 내용을 기존 폴더에 복사하여 같은 파일을 교체합니다. 02번·04번만 바꾸는 것이 아닙니다.
  2. 01_INSTALL_AND_CHECK.cmd: 설치·빌드 검사.
  3. 05_UPDATE_DATABASE.cmd: 새 DB 항목 추가. DATABASE_URL을 붙여 넣고 대상 호스트를 확인한 뒤 UPDATE 입력. 기존 기록은 유지합니다.
  4. 관리자 계정이 아직 없다면 06_SETUP_ADMIN.cmd 실행. Supabase URL·서버 키·DB 접속 정보를 준비하고 새 비밀번호를 직접 정합니다.
  5. 04_DEPLOY_PRODUCTION.cmd: Vercel 재배포. 연결이 없다면 02번에서 기존 gokbanjeong-gospel-class 선택 후 04번 실행.

자세한 설명은 같은 폴더의 DEPLOY_LATEST.md를 메모장으로 열어 읽으세요.

중요

일반 학습은 닉네임만으로 가능합니다. 저장 기록의 조회·관리는 이메일 로그인과 관리자 승인이 필요합니다. 기존 게스트 기록을 연결하려면 같은 브라우저에서 계정을 신청하세요.

AI 퀴즈·요약 생성에는 Vercel의 OPENAI_API_KEY와 정상 API 사용 설정이 필요합니다. 키를 등록한 뒤 반드시 재배포하세요. 준비된 추천 질문·토론은 API 없이 제공됩니다.

비밀번호와 API 키는 파일에 포함하지 않았습니다. 화면·대화에 공개했던 비밀번호와 2FA 등록 키는 교체하세요.
