# 2026년 48주차 영어 원문 대조

11월 23~29일 「여호와를 찾으라 그리하면 살리라」의 영어판 범위를 2026년 11월 23일 공식 HTML에서 확인했다. 아모스 9장, 오바댜 1장, 요나 4장의 215절과 교재가 별도로 지정한 성구를 배분된 항목별로 대조했다. 영어판도 월요일부터 토요일까지 읽으며 일요일에는 필수 자료가 없다.

- [한국어 원문 목록](2026-week-48-sources.json)에서 정한 86개 자료의 158개 학습 항목을 영어판에 연결했다. 영어 원문의 본문·그림 설명·서지정보·지정 매체는 1,862개 단위다. 각주 관련 단위는 621개로, 그중 609개가 인용 문단으로 연결되는 각주이고 12개는 각주 섹션의 제목이다. 해당 언어판에서 연결한 추가 탐색 자료는 원문 링크로 볼 수 있다.
- [영어 원문 조사 목록](2026-english-48-sources.json)은 공식 문서 경로, 언어, 해시, 원문 단위별 위치·절 번호·각주 소유자를 담고 있다. 전문은 공식 사이트에서 읽는다.
- [영어 읽기 범위](../../src/data/cfm-2026-week-48-english.json)는 원래 일차·과정·항목 ID에 연결된다. 원래 경로·언어·시작·끝·선택 단락 목록이 바뀐 경우 리더가 낡은 번역 위치를 사용하지 않도록 원본 범위도 기록한다.

| 위치 | 대조한 차이와 읽기 범위 |
|---|---|
| 교재의 선지자와 자비에 관한 문단 | 한국어 `p5`와 `p_cpCYU`의 질문·테 장로 말씀 소개가 영어에서는 `p5` 하나다. 한국어 `p16` 끝의 홀런드 장로 참조는 영어에서 별도 문단 `p_iKlGQ`로 이어진다. |
| 교재의 경전 도움말 | 한국어 `p_pueAg/p_mDCN3/p_kxrr6/p_ikipw/p_ovYrY`는 영어 `p_eSea6/p_dAXAE/p_qD7UF/p_kfhoD/p_wdCqL`에 각각 대응한다. 다림줄·니느웨·박넝쿨이라는 질문과 실제 연결 자료를 확인했다. |
| 교재 도입 | 영어 교재는 Bible Dictionary의 세 항목을 연결한다. 배정한 세 자료는 한국어 교재가 지정한 Guide to the Scriptures의 영어판이다. 영어 읽기 안내에도 이 차이를 표시한다. |
| 「선지자」 학습 안내서 | 한국어판 나아만 소개의 링크 표시는 “열왕기하 5:19”지만 실제 목적지와 영어판은 5:1–9이다. 이어지는 10–14절까지 배정한다. |
| 「나의 복음을 전파하라」 회복 공과 | 영어 `figure9_p2`, `figure15_p2`에 각각 배도·기도의 영어 참조 자료가 하나 더 있다. 해당 단락 앞의 경전 안내서 자료와 함께 원래 배정된 작업에 포함한다. |
| 배도 관련 자료와 어린이 노래 | 「배도」의 영어 글에는 추가 잡지·교회 지도자 말씀 등의 추천 목록이 있다. 「황금빛 봄날」은 언어판마다 가사 줄과 저작권 문단의 배치가 다르다. 둘 다 영어판 글·노래의 실제 끝까지 포함한다. |
| 재생기와 활동지 | 교재 `figure7`은 영어 “The Great Apostasy” 16:36, `figure8`은 “After the New Testament” 2:52이다. 한국어판 표시는 각각 16:29, 2:56이다. `figure5_img2`는 순종에 관한 영어 어린이 활동지 이미지다. 재생기·이미지의 위치와 표기를 확인했으며 영상 자막·PDF 내부는 별도로 대조하지 않았다. |
