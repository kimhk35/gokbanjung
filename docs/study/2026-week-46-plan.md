- 찬송·동요 5개, 구약전서 이야기 4편, 색칠 자료 2개, 어린이 지정 글 6개, 복음 그림책 23·25·26번 및 90~95번을 포함한다. 그림책 장 전체를 읽기로 배정하지 않는다.
- `주간 경전 놀이`와 `음식과 놀이`는 지정 활동을 담은 연결 글 전체다. 전자는 다른 11월 주차 활동도 포함하며, 앱에 ‘연결된 11월 글 전체’와 이어 읽기 순서를 표시했다. 그 글 안의 새 참조를 모두 재귀적으로 추가하지는 않는다.
- 각주의 설명·인용 자체는 포함한다. 각주에서 새로 연결한 문서 전체, 잡지 모음, 보조 예시 링크는 추가 탐색으로 남긴다. 판단은 링크 CSV에 기록했다.

## 언어·앵커 주의점

영어 원문 8개: Adam-ondi-Ahman, 어린이 노래 2개, 2026년 11월 어린이 글 5개. 노래의 한국어 경로는 실제로 목차로 연결됐고, 5개 글의 한국어 경로는 HTTP 404였다. 제공되는 영어 원문을 배정하고 앱 자료명에 언어를 표시했다. 한국어판이 어디에도 존재하지 않는다는 주장은 아니다.

복음 그림책의 원 교재 링크에 있는 `figure23` 등의 ID는 현재 HTML에 없다. `data-marker` 번호를 대조해 23번=`p45,p46,img23`, 25번=`p49,p50,img25`, 26번=`p51,p52,img26`, 90~95번=`p7..p18,img4..img9`로 확인했다. 읽기 선택은 실제 문단 ID를 사용하고 이미지 ID·URL은 미디어 목록에 기록한다.

도움말 비교표에는 모바일 카드 라벨에 표 머리글 두 ID가 각각 5번 복사되어 있다. 같은 표의 원본 머리글과 ID·본문·태그가 같은 카드 복사본만 제외했다. 다른 내용이나 각주를 가진 ID 충돌은 여전히 수집 오류로 중단한다. 모든 자료는 확인한 언어의 앵커로 잠그며 다른 번역의 대응 경계는 미검증이다.
