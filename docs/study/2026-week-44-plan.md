## 기준 범위와 조사 종료 조건

[공식 주간 교재](https://www.churchofjesuschrist.org/study/manual/come-follow-me-for-home-and-church-old-testament-2026/44?lang=kor)의 제목·성구·본문을 대조하여
**예레미야 31~33장, 36~39장, 예레미야애가 1장·3장**을 기준으로 확정했다.
경전 도움말의 제목·경로에는 여전히 36~38장이 남아 있다. 교재 본문은 39장 읽기를 명시하므로 39장을 포함했다.
기존 커리큘럼과 새로 만드는 로컬 DB의 seed 표시도 이 범위로 맞췄다. 운영 DB는 수정하지 않았다.

- 포함 문서 41개: 교재 전체, 경전 도움말 전체와 각주, 주간 경전 9개 장 전체, 비교 성구 니파이전서 1~2장 전체, 직접 지정된 추가 성구, 경전 안내서 2개, 본문·도움말에서 지정한 말씀, 교사 학습 자료, 어린이 추가 자료 목록과 개별 글·노래.
- 추가 성구 범위: 예레미야 1:10; 마태복음 5:4; 야고보서 4:8~10; 앨마서 36:17~20; 모사이야서 18:10, 13. 이 자료들은 해당 절과 그 절의 각주만 포함한다.
- 밸라드 말씀은 한국어 경로가 404여서 실제 제공되는 영어 전문을 3일에 나눴다. 한국어판이 없다는 보편적인 주장 대신 이번 경로의 확인 결과를 기록한다.
- 교사 방송은 원문에 표시된 전체 영상 76:22를 연결한다. HTML에는 제목·연사·날짜만 있어, 그 5개 메타데이터 단위를 조사했다. 영상 전문·자막·장면별 내용까지 조사했다고 주장하지 않는다.
- `친구들` 잡지 모음, 각 글의 각주에서 새로 연결한 문서, 교사 학습 자료 안의 추가 성구·말씀은 추가 탐색으로 보존한다. 이들을 다시 재귀적으로 읽기 분량에 넣지는 않았다.
- 어린이 목록에서 이름이 지정된 개별 글은 전체를 포함한다. `주간 경전 놀이`는 연결 글의 다른 10월 주차 활동까지 포함하는 전체 글이다. 그 사실을 앱 자료명에 표시했다.
- 원문 그림·색칠·악보·PDF는 공식 페이지와 파일 링크를 보존한다. 이미지·음원·PDF를 다운로드하거나 앱에 복제하지 않았다. 그림 속 글자 및 PDF 전체 페이지의 텍스트 검증은 수행하지 않았다.

## 7일 배분

교재는 소제목과 질문의 문맥을 유지하고, 긴 연결 말씀은 원문의 논점이 끝나는 문단 경계에서 나눴다.
자료명에 `1/3`, `2/3` 등의 이어 읽기 순서를 표시한다. 가족 과정과 질문 답변은 기본 과정 완료 조건과 분리한다.
교사 학습 자료의 `n/7`은 원문의 소주제 번호이며 일차 번호가 아니다. 소주제는 그날 질문에 맞춰 1→4→2→3→5→6→7 순으로 배치했다.

공식 교재 안에 원래 있는 성구 인용·참조 링크는 보존한다. 이를 별도의 다시 읽기 항목으로 배정하지 않는다.
남은 항목의 ID와 원문 범위는 유지해 기존 완료 기록이 다른 자료를 가리키지 않게 했다. 제거한 ID는 재사용하지 않는다.

중복 바로가기에는 새 원문 단위가 없었으므로 위 문자·단어·절·각주 집계는 변하지 않는다.

**전체 소요 시간의 균등 배분은 검증되지 않았다.** 3일차에 연결한 76:22 교사 방송이 가장 큰 추가 부담이며, 영상 전문이 없어 내용 경계별 재분할은 하지 않았다.
이를 제외한 읽기 분량의 비교와 영상·활동까지 포함한 총 학습 부담을 구분한다. 실제 참여자의 학습 시간은 측정하지 않았다.

원문 페이지에 표시된 재생 길이: 워커 8:23, 베드나 13:26, 앤더슨 13:32, 쿡 14:34, 밸라드 17:59, 교사 방송 76:22, 교사 학습 자료 영상 2:51.
읽기와 동일한 말씀의 전체 영상은 대안이며 읽기 분량에 영상 전체를 중복 합산하지 않았다. 실제 재생·자막 정확도는 검사하지 않았다.

## 재현과 변경

새 조사 폴더를 사용해 아래 수집을 수행하고, 해시·누락·경계 변경을 검토한 후 배분과 버전을 갱신한다.

python scripts/study/audit-sources.py docs/study/2026-week-44-sources.json test-results/week44

배분 스크립트의 문단 경계는 이번에 확인한 원문 전용이며, 다음 주차에 숫자만 바꾸어 재사용하지 않는다.
