# 와서 나를 따르라 7일 학습 분량 배분 방법

상태: 2026-10-18 기준, 2026년 43주차(10월 19~25일)에 적용한 작업 기준.
적용 데이터: `src/data/cfm-2026-week-43.json`.
원문 전체를 재작성하거나 요약해서 옮기는 방식이 아니라 **공식 원문의 위치를 배정하는 방식**이다.

## 반드시 지킬 원칙

1. 한 주의 원문을 먼저 전부 조사한 뒤 배분한다. 경전 장 수만 7등분하지 않는다.
2. 하루에 하나의 핵심 질문을 두고, 그 질문과 관련된 교재의 원문 범위를 완결한다.
3. 내용은 줄이거나 생략하지 않는다. 연결 경전·말씀의 본문과 각주도 조사 목록에 포함한다.
4. 기본 학습과 어린이·가족 활동은 서로 다른 과정이다. 기본 학습 뒤에 가족 활동을 숨기거나, 가족 과정을 해야만 기본 학습이 완료되는 구조로 만들지 않는다.
5. 긴 연결 말씀은 자연스러운 소주제·문단 경계로 나눌 수 있다. 어느 날 어느 문단에서 이어지는지 명시하고, 합쳤을 때 본문·각주가 전부 남아 있어야 한다.
6. ‘교재에 쓰인 질문’과 ‘교사가 게시한 오늘의 질문’을 구분한다. 교사 질문은 학습을 돕는 선택 참여이며, 답변을 완료 조건으로 삼지 않는다.
7. 확인하지 않은 자료·언어·주차를 ‘검증 완료’로 표시하지 않는다. 기존 주차의 배분을 URL 숫자만 바꿔 재사용하지 않는다.

## 1. 기준 원문과 조사 범위 확정

- 연도·주차·날짜·교재 제목·공식 URL·언어를 기록한다.
- 공식 페이지의 도입, 성구 표시, 모든 소제목, 본문 문단, 인용문, 그림 설명, 어린이 섹션, 학습 팁, 자료 안내, 영상·활동지 링크를 끝까지 확인한다.
- 직접 연결된 경전은 표시된 절 범위와 주간 제목에 제시된 장 범위를 함께 대조한다. 본문의 절 몇 개를 읽었다고 주간 장 전체를 읽은 것으로 계산하지 않는다.
- 직접 연결된 말씀·학습 글은 해당 글 전체의 본문·각주를 조사한다. 교재가 인용한 짧은 문단만 조사하고 전체 말씀을 포함했다고 말하지 않는다.
- 잡지 전체, 주제별 검색 목록, 그림 자료 모음처럼 범위가 열려 있는 링크는 ‘추가 탐색 링크’로 별도 표기한다. 그 사이트의 모든 하위 문서를 읽을 분량에 포함한 것으로 주장하지 않는다. 교사가 특정 자료를 지정하면 그 문서를 별도로 조사·배정한다.

43주차 기준 원문:
[예레미야 1~3장; 7장; 16~18장; 20장](https://www.churchofjesuschrist.org/study/manual/come-follow-me-for-home-and-church-old-testament-2026/43?lang=kor).

## 2. 화면의 줄이 아닌 원문 단위에 번호 부여

화면의 줄 수는 기기 폭·글자 크기·언어에 따라 바뀐다. 따라서 화면에 보이는 줄 수로 누락을 검사하지 않는다.

- 안정적인 문단·제목·그림 설명·각주 ID를 기준으로 자료별 연속 번호를 매긴다.
- 각 단위에 `sourceId`, 공식 `path`, `anchor`, 번호, 일차, 과정, 작업 ID를 기록한다.
- 원문이 하나의 블록에 여러 문장을 넣었다면 그 블록을 나누기 위해 문장을 임의로 삭제하거나 편집하지 않는다.
- 기본 키는 `sourceId#anchor`이다. 번호는 조사·대조용이며 원문 자체의 절 번호와 혼동하지 않는다.
- 본문 원문은 앱 데이터에 복제하지 않는다. 앱에는 위치·제목·배정 정보만 둔다.

43주차 조사표: [전체 원문 단위 목록](2026-week-43-source-inventory.csv).
이 조사표는 이전 목업에서 대조한 25개 문서의 1,117개 단위이다. 번호는 ‘화면의 1,117줄’이라는 뜻이 아니다.

## 3. 교재를 주제 묶음으로 나누기

먼저 교재의 자연스러운 소제목과 질문을 기준으로 묶는다. 각 묶음에 다음을 붙인다.

| 항목 | 기록할 내용 |
|---|---|
| 핵심 질문 | 그날 생각할 한 가지 질문 |
| 교재 범위 | 시작·끝 문단, 포함 소제목·인용·그림 설명 |
| 경전 | 책·장·절, 장 전체인지 일부인지 |
| 연결 말씀 | 자료 제목, 전체 또는 오늘 배정한 시작·끝 |
| 각주 | 해당 자료의 각주와 본문 인용 위치 |
| 영상 | 제목과 원문 내 재생 위치, 별도 자료로 표시 |
| 활동 | 실제로 해야 하는 행동, 개인/가족 구분 |
| 추가 탐색 | 잡지·검색·자료 모음 등 범위가 열린 링크 |

교재의 한 소제목을 둘 이상 날에 나눠야 한다면, 첫날의 끝과 다음 날의 시작을 문단 ID로 연결한다. 인용문·질문·그 설명을 중간에서 끊지 않는 것을 우선한다. 편집상 필요하면 한 소제목을 다시 보여 줄 수 있지만, 본문 배정은 중복 계산하지 않는다.

## 4. 7일에 배정하고 학습 부담 조정

1. 도입과 핵심 교재 묶음을 먼저 배정한다.
2. 관련 경전·말씀·각주를 붙인다. 이미 한 번 전체 배정한 동일 자료가 다시 참조되면 중복 읽기를 필수 분량처럼 계산하지 않고 바로가기만 제공할 수 있다.
3. 긴 말씀은 소주제가 끝나는 지점에서 나누어 분산한다. 다음 날에 갑자기 문맥 없이 시작하지 않도록 제목과 범위 안내를 제공한다.
4. 어린이·가족은 별도 7일 배정표를 만든다. 기본 학습과 같은 본문을 사용하는 경우 `shared`로 연결하고, 가족 활동 설명은 유지한다. 새 본문이 0개인 날에도 활동이 없다는 뜻은 아니다.
5. 문단 수만 맞추지 않는다. 경전의 길이, 긴 말씀, 각주, 영상, 실제 활동, 생각할 질문의 부담을 따로 본다.
6. 한 날이 무거우면 연결 자료의 자연스러운 묶음을 앞뒤 날로 옮긴다. 해당 날의 핵심 교재 질문은 완결되게 유지한다.
7. 실제 참여자의 읽기·활동 기록이 없으면 ‘실제 46분’ 같은 정확한 학습 시간으로 표현하지 않는다. 현재 UI에는 예상 시간을 표시하지 않는다. 분량의 균형과 개인이 걸리는 시간은 다른 지표다.

## 5. 누락·중복을 집합으로 검사

조사한 모든 단위의 집합을 `U`, 각 날·과정에 배정한 단위의 집합을 `A1…An`이라 한다.

- 누락: `U - union(Ai)`가 비어 있어야 한다.
- 조사에 없던 배정: `union(Ai) - U`가 비어 있어야 한다.
- 중복: 본문을 소유한 배정들 사이에 같은 `sourceId#anchor`가 두 번 나오면 안 된다.
- 공유 바로가기: `shared` 자료는 이미 배정된 원문을 가리키며 새 본문 소유 단위로 다시 세지 않는다.
- 각주·그림 설명·어린이 활동·영상·외부 참조는 본문과 별도의 목록으로도 확인한다. 본문 문단만 모두 배정했다고 모든 자료가 처리된 것은 아니다.

43주차는 조사 범위 안에서 **25개 문서, 1,117개 단위, 경전 217절, 연결 메시지/학습 글 9개**를 대조했다. 이는 모든 링크를 재귀적으로 따라간 인터넷 전체 자료에 대한 수치가 아니다.

| 일차 | 핵심 주제 | 기본 원문 단위 | 어린이·가족 원문 단위 |
|---|---|---:|---:|
| 1 | 선지자의 부름 | 172 | 6 |
| 2 | 정체성 발견 | 138 | 13 |
| 3 | 정체성의 적용 | 143 | 3 |
| 4 | 생수의 근원 | 160 | 0 (공유 원문·실물 활동) |
| 5 | 진실한 예배 | 180 | 3 |
| 6 | 집합에 참여하기 | 151 | 9 |
| 7 | 주님의 인도 | 133 | 6 |
| 합계 | | 1,077 | 40 |

기본 학습의 앱 자료 항목은 영상·돌아보기 활동을 포함해 67개이다. 이 항목 수를 1,117개 원문 단위와 혼동하지 않는다. 진행률은 사용자가 읽었다고 확인한 **앱 자료 항목 수**를 기준으로 계산한다. 가족 과정과 질문 참여는 따로 표시한다.

## 6. 앱 데이터로 옮기기

현재 구조:

- `src/data/cfm-2026-week-43.json`: 배정한 위치·자료·단위 목록. 시간이나 원문 전체를 싣지 않는다.
- `src/lib/cfm-study-plan.ts`: 범위, 공식 URL, 진행률 계산.
- `src/components/learning/study-reader.tsx`: 일차·과정·자료 전환과 공식 원문 읽기.
- `src/lib/study-material-progress.ts`: 계정별 자료 확인 기록. 질문 답변과 독립.

새 주차를 추가할 때 이 문서의 조사·대조 절차를 먼저 수행하고, 별도의 주차 데이터 파일을 만든다. 검증된 데이터가 없는 주차에 43주차 분량을 덮어쓰지 않는다. 주차 등록 함수·라우팅·테스트도 함께 확장한다.

자료별 필수 필드:

- `id`: 주차 안에서 안정적인 작업 ID. 재배분해도 의미가 같은 자료는 ID를 함부로 바꾸지 않는다.
- `path`, `sourceLang`: 공식 원문과 실제 제공 언어. 영어로만 제공되는 자료는 그 사실을 유지한다.
- `anchor`, `endAnchor`: 처음·끝 이동 위치.
- `sourceIds`, `units`: 조사·누락 대조를 위한 전체 단위.
- `selectedIds`: 화면에서 파란 선으로 표시할 본문·소제목·설명 단위. 주석 컨테이너나 페이지 전체 컨테이너를 그대로 선택하지 않는다.
- `noteLinks`: 각주와 인용 본문의 연결 위치.
- `kind`: 교재, 경전, 연결 말씀, 공유 원문, 영상, 활동의 성격.

## 7. 파란 선과 이동을 실제 브라우저에서 확인

공식 사이트의 `?id=문단ID1,문단ID2,…`와 `#이동위치`를 사용한다. 외부 iframe DOM을 앱이 수정해서 파란 선을 만든다고 가정하지 않는다.

- 일차를 고르면 그날 첫 자료의 지정 범위가 바로 열린다.
- ‘시작 보기’와 ‘끝 보기’는 **전체 selectedIds를 유지한 채** 이동 위치만 바꾼다.
- 하루의 마지막 본문과 다음 날 첫 본문 사이에 배정되지 않은 문단이 없는지 조사표와 대조한다.
- 시작·끝 문단, 소제목, 그림 설명에서 실제 파란 선을 확인한다. 그림 설명에만 선이 생겼는데 본문 전체가 선택됐다고 보고하지 않는다.
- 공식 상단 도구막대가 시작 문장을 가리지 않는지 확인한다. 원문 주변 문맥이 조금 보이는 것과 배정 범위가 틀리는 것은 구분한다.
- 각주와 영상은 별도 자료·바로가기로 접근 가능해야 한다.
- 어린이·가족 칩에서도 올바른 원문과 활동으로 이동해야 한다.
- 지원 언어마다 문단 ID가 실제 존재하는지 확인한다. 언어별 앵커가 다르거나 자료가 없으면 확인된 대체 자료 또는 공식 새 창 경로를 안내한다.
- 현재 43주차 구현은 임의 생성 문단 ID(`p_…`)가 있는 자료를 조사한 원문 언어로 유지하고 안내한다. 영어 전용 자료는 영어로 연다. 지원 언어로 URL을 만드는 자동 검사와, 각 번역의 모든 문단 경계를 실제 대조하는 작업은 다르다. 네 언어의 모든 경계 검증이 끝났다고 표시하지 않는다.
- iframe 표시가 막히면 항상 보이는 ‘원본·개인 주석’ 링크를 사용한다. 교회 계정 로그인·주석 저장이 iframe에서 항상 가능하다고 약속하지 않는다.

## 8. 공개 전 확인과 유지보수

- 자동 검사: `tests/study-plan.test.ts`(단위 수·중복·범위·언어 URL), `tests/study-material-progress.test.ts`(본인 기록·완료 조건), `tests/study-community.test.ts`(질문 배정·공개/비공개).
- 자동 검사는 실시간 공식 사이트의 본문이 변경되지 않았음을 증명하지 않는다. 새 주차를 등록하거나 원문이 갱신되면 브라우저 대조도 다시 한다.
- 화면 검증: 휴대폰 폭, 태블릿 폭, 컴퓨터 폭에서 첫 문장·끝 문장·칩·질문 입력란·키보드 접근을 확인한다. 브라우저 크기 변경 검증과 실제 휴대폰 검증은 보고서에서 구분한다.
- 질문 링크로 들어온 손님이 질문을 읽고 이름 없이 답할 수 있는지 확인한다. 작성 중 초안과 개인 기록이 공개 모음에 섞이면 안 된다.
- 배분 변경 시 원문 변경 여부, 이전/이후 단위 배정, 이유, 실행한 검사와 남은 불확실성을 기록한다.
- 본문이 바뀌거나 자료 ID가 달라지면 기존 완료 기록을 새 자료에 자동 적용하지 않는다. 데이터 버전과 기록 이관 방침을 먼저 정한다.
- 운영 DB 마이그레이션·배포는 별도 절차이다. 배분 데이터나 로컬 브랜치 작업만으로 운영 DB를 수정하지 않는다.
