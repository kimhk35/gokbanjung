# 와서 나를 따르라 7일 학습 분량 배분 방법

상태: 2026-10-18 기준, 2026년 43주차(10월 19~25일)에 적용한 작업 기준.
적용 데이터: `src/data/cfm-2026-week-43.json`.
2026-10-25에 조사 종료 조건·분량 비교·검증 기록 양식을 보강했다. 새 적용 사례는 [44주차 배분표](2026-week-44-plan.md)를 참조한다.
원문 전체를 재작성하거나 요약해서 옮기는 방식이 아니라 **공식 원문의 위치를 배정하는 방식**이다.

보강: 2026-10-25에 조사 범위의 종료 조건, 일별 부담 비교, 원문 대조 기록 양식을 추가했다. 아래 양식은 다음 주차 작업을 위한 기준이며, 43주차나 다른 주차에서 새 검증을 수행했다는 기록은 아니다.

## 반드시 지킬 원칙

1. 한 주의 원문을 먼저 전부 조사한 뒤 배분한다. 경전 장 수만 7등분하지 않는다.
2. 하루에 하나의 핵심 질문을 두고, 그 질문과 관련된 교재의 원문 범위를 완결한다.
3. 내용은 줄이거나 생략하지 않는다. 연결 경전·말씀의 본문과 각주도 조사 목록에 포함한다.
4. 기본 학습과 어린이·가족 활동은 서로 다른 과정이다. 기본 학습 뒤에 가족 활동을 숨기거나, 가족 과정을 해야만 기본 학습이 완료되는 구조로 만들지 않는다.
5. 긴 연결 말씀은 자연스러운 소주제·문단 경계로 나눌 수 있다. 어느 날 어느 문단에서 이어지는지 명시하고, 합쳤을 때 본문·각주가 전부 남아 있어야 한다.
6. ‘교재에 쓰인 질문’과 ‘교사가 게시한 오늘의 질문’을 구분한다. 교사 질문은 학습을 돕는 선택 참여이며, 답변을 완료 조건으로 삼지 않는다.
7. 확인하지 않은 자료·언어·주차를 ‘검증 완료’로 표시하지 않는다. 기존 주차의 배분을 URL 숫자만 바꿔 재사용하지 않는다.

## 1. 기준 원문과 조사 범위 확정

- 연도·주차·날짜·교재 제목·공식 URL·언어를 기록한다.
- 공식 페이지의 도입, 성구 표시, 모든 소제목, 본문 문단, 인용문, 그림 설명, 어린이 섹션, 학습 팁, 자료 안내, 영상·활동지 링크를 끝까지 확인한다.
- 직접 연결된 경전은 표시된 절 범위와 주간 제목에 제시된 장 범위를 함께 대조한다. 본문의 절 몇 개를 읽었다고 주간 장 전체를 읽은 것으로 계산하지 않는다.
- 직접 연결된 말씀·학습 글은 해당 글 전체의 본문·각주를 조사한다. 교재가 인용한 짧은 문단만 조사하고 전체 말씀을 포함했다고 말하지 않는다.
- 잡지 전체, 주제별 검색 목록, 그림 자료 모음처럼 범위가 열려 있는 링크는 ‘추가 탐색 링크’로 별도 표기한다. 그 사이트의 모든 하위 문서를 읽을 분량에 포함한 것으로 주장하지 않는다. 교사가 특정 자료를 지정하면 그 문서를 별도로 조사·배정한다.

### 1.1 포함 범위와 조사 종료 조건

배분 전에 자료 목록(source manifest)을 확정한다. ‘원문 전체’는 이 목록에 포함하기로 정한 자료의 전체를 뜻한다. 조사 도중 연결 문서가 발견되면 아래 기준으로 포함 여부와 이유를 기록한다.

1. 해당 주 교재 전체와 교재가 직접 지정한 경전 범위·말씀·학습 글을 포함한다. 경전은 주간 제목의 전체 장 범위와 본문에서 별도로 지정한 절 범위를 모두 목록에 남긴다.
2. 교재가 직접 연결한 학습 팁·자료 안내 등 범위가 정해진 보조자료도 포함한다. 그 보조자료가 제목·링크로 특정 글을 학습 대상으로 명시하면, 해당 글들을 목록에 개별 등록하고 본문·각주 전체를 포함한다. 자료 모음의 모든 글이나 보조자료의 모든 참조 링크를 자동으로 포함하지 않는다.
3. 연결 말씀·학습 글의 각주에 적힌 설명과 인용은 그 자료의 일부로 포함한다. **각주가 새로 링크한 문서 전체까지 자동으로 조사 범위를 확장하지 않는다.** 그 문서가 교재나 확정된 보조자료에서 별도로 명시된 학습 대상이면 그 근거로 포함한다.
4. 영상·활동지·실물 활동은 원문 내 위치와 실제 자료를 목록에 기록한다. 본문 단위가 없다는 이유로 목록에서 제외하지 않는다.
5. 조사 대상 원문의 본문·각주 안에서 포함하지 않는 링크는 모두 ‘추가 탐색’ 목록에 원문 위치·대상·미포함 이유를 남긴다. 검색·자료 모음, 각주의 추가 참조, 다른 주차 이동처럼 미포함 이유를 구체적으로 적는다. 같은 대상의 반복 링크는 한 항목에 출현 위치를 모아 기록해도 된다. 사이트 공통 메뉴·도구막대 링크는 이 조사 대상이 아니다.
6. 포함 대상인데 접근할 수 없거나 지정 범위가 불명확한 자료는 ‘미확인’으로 남긴다. 이를 추가 탐색으로 바꾸어 조사 완료 처리하지 않는다. 공식 제목·본문·앱의 범위가 다르면 각각의 근거를 기록하고, 공식 원문 대조로 기준 범위를 정한 뒤 배분한다.

교재의 처음부터 끝까지 확인했고, 조사 대상 원문의 본문·각주 링크를 위 기준으로 분류했으며, 포함 자료와 보조자료에서 명시한 글의 목록·범위가 확정되면 조사 대상을 닫는다. 이후 발견한 자료는 포함 여부·이유·목록 변경일을 기록해 추가한다. 각주의 추가 링크를 끝없이 따라가는 것을 종료 조건으로 삼지 않는다. 범위 확정과 각 자료의 본문 단위 수집 완료는 별도로 판정한다.

### 1.2 자료 목록 양식

다음은 **빈 작성 양식**이다. `<…>`는 실제 확인값으로 바꿀 자리이며, 확인하지 않은 수치나 URL을 채운 예시가 아니다. 주차별 조사표와 함께 저장하고, 반복 참조하는 동일 문서는 하나의 `sourceId`로 관리한다. 영상·활동도 고유 ID를 둔다.

```text
| sourceId | 종류 | 지정 근거(상위 sourceId#anchor) | 공식 URL·실제 언어 | 포함 범위(장·절/처음·끝 ID/전체) | 포함 이유 | 원문 확인일 | 검증 상태 |
|---|---|---|---|---|---|---|---|
| <자료 ID> | <교재/경전/말씀/보조자료/영상/활동> | <직접 지정 위치 전부> | <URL, kor/eng 등> | <확정 범위> | <포함 규칙과 근거> | <YYYY-MM-DD 또는 미확인> | <미확인/부분 확인/해당 범위 확인> |

| 원문 내 링크 위치 | 링크 대상·언어 | 처리 | 미포함 이유 또는 포함 sourceId | 확인일·남은 불확실성 |
|---|---|---|---|---|
| <sourceId#anchor> | <공식 URL·언어> | <추가 탐색/포함/미확인> | <구체적 이유 또는 자료 ID> | <확인값 또는 미확인 사유> |
```

[예레미야 1~3장; 7장; 16~18장; 20장](https://www.churchofjesuschrist.org/study/manual/come-follow-me-for-home-and-church-old-testament-2026/43?lang=kor).

## 2. 화면의 줄이 아닌 원문 단위에 번호 부여

화면의 줄 수는 기기 폭·글자 크기·언어에 따라 바뀐다. 따라서 화면에 보이는 줄 수로 누락을 검사하지 않는다.

- 안정적인 문단·제목·그림 설명·각주 ID를 기준으로 자료별 연속 번호를 매긴다.
- 각 단위에 `sourceId`, 공식 `path`, `anchor`, 번호, 일차, 과정, 작업 ID를 기록한다.
- 원문이 하나의 블록에 여러 문장을 넣었다면 그 블록을 나누기 위해 문장을 임의로 삭제하거나 편집하지 않는다.
- 기본 키는 `sourceId#anchor`이다. 번호는 조사·대조용이며 원문 자체의 절 번호와 혼동하지 않는다.
- 본문 원문은 앱 데이터에 복제하지 않는다. 앱에는 위치·제목·배정 정보만 둔다.

43주차 조사표: [전체 원문 단위 목록](2026-week-43-source-inventory.csv).
이 조사표는 이전 목업에서 대조한 25개 문서의 1,117개 단위이다. 번호는 ‘화면의 1,117줄’이라는 뜻이 아니다.

## 3. 교재를 주제 묶음으로 나누기

먼저 교재의 자연스러운 소제목과 질문을 기준으로 묶는다. 각 묶음에 다음을 붙인다.

| 항목 | 기록할 내용 |
|---|---|
| 핵심 질문 | 그날 생각할 한 가지 질문 |
| 교재 범위 | 시작·끝 문단, 포함 소제목·인용·그림 설명 |
| 경전 | 책·장·절, 장 전체인지 일부인지 |
| 연결 말씀 | 자료 제목, 전체 또는 오늘 배정한 시작·끝 |
| 각주 | 해당 자료의 각주와 본문 인용 위치 |
| 영상 | 제목과 원문 내 재생 위치, 별도 자료로 표시 |
| 활동 | 실제로 해야 하는 행동, 개인/가족 구분 |
| 추가 탐색 | 잡지·검색·자료 모음 등 범위가 열린 링크 |

교재의 한 소제목을 둘 이상 날에 나눠야 한다면, 첫날의 끝과 다음 날의 시작을 문단 ID로 연결한다. 인용문·질문·그 설명을 중간에서 끊지 않는 것을 우선한다. 편집상 필요하면 한 소제목을 다시 보여 줄 수 있지만, 본문 배정은 중복 계산하지 않는다.

## 4. 7일에 배정하고 학습 부담 조정

1. 도입과 핵심 교재 묶음을 먼저 배정한다.
2. 관련 경전·말씀·각주를 붙인다. 이미 한 번 전체 배정한 동일 자료가 다시 참조되면 중복 읽기를 필수 분량처럼 계산하지 않고 바로가기만 제공할 수 있다.
3. 긴 말씀은 소주제가 끝나는 지점에서 나누어 분산한다. 다음 날에 갑자기 문맥 없이 시작하지 않도록 제목과 범위 안내를 제공한다.
4. 어린이·가족은 별도 7일 배정표를 만든다. 기본 학습과 같은 본문을 사용하는 경우 `shared`로 연결하고, 가족 활동 설명은 유지한다. 새 본문이 0개인 날에도 활동이 없다는 뜻은 아니다.
5. 문단 수만 맞추지 않는다. 경전의 길이, 긴 말씀, 각주, 영상, 실제 활동, 생각할 질문의 부담을 따로 본다.
6. 한 날이 무거우면 연결 자료의 자연스러운 묶음을 앞뒤 날로 옮긴다. 해당 날의 핵심 교재 질문은 완결되게 유지한다.
7. 실제 참여자의 읽기·활동 기록이 없으면 ‘실제 46분’ 같은 정확한 학습 시간으로 표현하지 않는다. 현재 UI에는 예상 시간을 표시하지 않는다. 분량의 균형과 개인이 걸리는 시간은 다른 지표다.

### 4.1 일별 비교표와 집계 규칙

기본 학습과 어린이·가족을 **각각** 7일 표로 작성한다. 아래는 빈 양식이다. `<1~7>` 행을 일차별로 만들고, `<…>`는 실제 측정값이나 구체적인 설명으로 바꾼다. 확인할 수 없는 값은 0 대신 ‘미확인’으로 쓴다. 0은 확인 결과 해당 분량이 없을 때만 쓴다.

```text
| 일차·과정 | 핵심 질문 | 한국어 공백 제외 글자 수 | 영어 단어 수 | 경전 절 수 | 각주 수 | 영상 길이 | 활동 종류·부담 | 공유 원문 | 조정 판단·이유 |
|---|---|---|---|---|---|---|---|---|---|
| <1~7, 기본/가족> | <질문> | <측정값/미확인> | <측정값/미확인> | <측정값/미확인> | <측정값/미확인> | <합계 분:초/미확인> | <활동·준비물·함께할 사람·횟수 등> | <sourceId와 원 배정 일차> | <유지/재분산 검토, 근거> |
```

- 한국어 자료는 배정된 본문·소제목·그림 설명·각주 텍스트에서 공백을 제거한 문자 수를 센다. 영어 자료는 같은 범위의 텍스트를 공백으로 나눈 비어 있지 않은 어절 수를 센다. 사이트 메뉴·도구막대는 제외한다. 측정 방법과 언어를 기록하고, 같은 원문을 두 언어로 모두 읽도록 배정한 경우가 아니면 번역본까지 중복 합산하지 않는다.
- 경전 절 수와 각주 수는 각각 배정된 고유 절·각주 본문의 수이다. 경전·각주 텍스트가 글자 수나 단어 수에 이미 들어 있다면 별도의 읽기 분량처럼 다시 더하지 않는다. 각주 링크 수와 각주 본문 수를 혼동하지 않는다.
- 동일한 `sourceId#anchor`의 반복 참조와 `shared`는 주간 원문 총량에 다시 더하지 않는다. 가족 표에는 공유 범위를 따로 표시해 실제로 읽는 맥락과 활동 부담을 검토한다. 기본·가족 두 과정을 함께 하는 사람의 부담을 계산할 때도 공유 본문을 두 번 더하지 않는다.
- 영상은 실제 배정한 영상·구간의 길이를 기록한다. 길이를 확인하지 못한 링크는 미확인으로 남긴다. 활동은 읽기와 구분하여 준비·대화·만들기 등의 행동과 반복 횟수를 적는다. 활동 시간을 추정한다면 측정된 재생 시간과 구분하여 ‘추정’으로 표시한다.

### 4.2 측정치와 재분산 판단 구분

글자·단어·절·각주 수와 확인된 영상 길이는 측정치이다. 주제 난도, 활동의 준비 부담, 한 질문을 완결하는 데 필요한 문맥은 편집자의 판단이다. 서로 다른 측정 단위를 더해 하나의 총점이나 보장된 학습 시간으로 표현하지 않는다.

다음은 **재분산 검토를 시작하는 휴리스틱**이며 자동 탈락 기준이나 실제 소요 시간의 보장이 아니다.

- 같은 과정·같은 언어에서 한 날의 글자 수 또는 단어 수가 7일 중앙값의 1.5배를 넘으면 검토한다. 중앙값이 0이거나 미확인 값이 있으면 이 비율로 균형을 판정하지 않고, 배정된 자료와 불확실성을 직접 비교한다.
- 읽기 분량이 가장 많은 날에 긴 영상이나 준비가 필요한 활동까지 겹치거나, 읽기 분량이 적은 날에도 여러 활동이 몰리면 검토한다. 영상·활동의 가벼움/무거움 판단 근거를 표에 남긴다.
- 조정할 때는 긴 말씀·연결 경전의 자연스러운 소주제나 문단 묶음을 앞뒤 날로 옮긴다. 교재의 핵심 질문·인용·설명은 완결되게 유지하고, 옮긴 자료의 시작·끝 ID와 이어 읽기 안내를 갱신한다.
- 균형을 맞추기 위해 포함 자료의 본문·각주를 생략하거나 추가 탐색으로 바꾸지 않는다. 재분산 후에도 무거운 날이 남으면 이유와 남은 부담을 기록한다. 질문의 완결성과 7일 내 전체 범위 보존을 함께 만족하기 어려우면 해결되지 않은 배분 판단으로 남기며, 균형 검증 완료라고 표시하지 않는다.
- 조정 후 비교표를 다시 집계하고 5번 절차의 누락·중복 검사를 수행한다. 기본 과정의 부담을 가족 과정으로 떠넘겨 기본 완료를 가족 활동에 종속시키지 않는다.

## 5. 누락·중복을 집합으로 검사

조사한 모든 단위의 집합을 `U`, 각 날·과정에 배정한 단위의 집합을 `A1…An`이라 한다.

- 누락: `U - union(Ai)`가 비어 있어야 한다.
- 조사에 없던 배정: `union(Ai) - U`가 비어 있어야 한다.
- 중복: 본문을 소유한 배정들 사이에 같은 `sourceId#anchor`가 두 번 나오면 안 된다.
- 공유 바로가기: `shared` 자료는 이미 배정된 원문을 가리키며 새 본문 소유 단위로 다시 세지 않는다.
- 중복 읽기 없이 배분하라는 요청이 있으면 `shared` 바로가기도 일별 읽기 목록에서 제외한다. 가족 활동 설명은 유지하되, 원문을 여는 `selectedIds`가 그 항목의 `sourceIds`에 속하는지, 같은 공식 경로·언어·문단이 다른 날이나 과정에서 다시 선택되지 않는지도 별도로 검사한다. 44주차는 2026-10-26에 이 기준을 적용했다. 공식 원문 자체의 인용·참조 링크는 보존하며, 이를 별도 읽기 항목으로 다시 배정하지 않는다.
- 각주·그림 설명·어린이 활동·영상·외부 참조는 본문과 별도의 목록으로도 확인한다. 본문 문단만 모두 배정했다고 모든 자료가 처리된 것은 아니다.

### 5.1 원문과 조사 목록을 별도로 대조

집합 검사는 조사 목록 `U`에 처음부터 들어오지 않은 자료를 찾지 못한다. 따라서 **공식 원문 → 자료 목록 → 원문 단위 조사표**의 완전성 대조와 **조사표 → 앱 배정 데이터**의 집합 검사를 별도로 기록한다. 기존의 원문 전체 확인·브라우저 대조를 아래 양식으로 남기는 것이며, 자동 검사의 통과를 원문 조사 완료로 대신하지 않는다.

1. 자료 목록의 지정 근거를 교재 원문과 대조하고, 직접 보조자료 및 거기서 명시한 글이 빠지지 않았는지 확인한다. 추가 탐색으로 분류한 링크의 이유도 함께 검토한다.
2. 각 포함 자료를 처음부터 끝까지 읽으며 제목·본문·인용·그림 설명·각주·영상·활동을 조사표와 대조한다. 조사표의 마지막 행이 원문의 마지막 배정 대상과 일치하는지도 확인한다. 각주 목록이 접혀 있으면 펼쳐 확인한다.
3. 원문에서 확인한 시작·끝 ID, 단위 수, 별도 자료 수와 조사표의 값을 비교한다. 일치하는 총수만으로 중간 문단까지 확인했다고 판단하지 않고, 누락·중복·순서 차이의 위치를 기록한다.
4. 접근 불가·언어별 차이·ID 부재·공식 범위 불일치는 미확인 항목으로 남긴다. 원문이 변경되면 확인일과 영향을 받은 자료를 갱신하고 필요한 대조를 다시 한다.

다음은 **빈 대조 기록 양식**이다. 표의 `<…>`는 확인 후 채울 자리이며, 43주차의 새로운 검증 결과가 아니다.

```text
| 확인일·확인자 | sourceId·공식 URL·언어 | 대조 종류 | 원문에서 확인한 범위·수 | 목록/배정의 범위·수 | 결과·근거 | 미확인 사항·다음 조치 |
|---|---|---|---|---|---|---|
| <YYYY-MM-DD, 확인자> | <자료 ID, URL, 언어> | <원문→자료 목록/원문→단위 조사표/조사표→배정/실화면> | <시작·끝 ID, 종류별 수> | <파일·자료 ID, 해당 값> | <일치/차이/미확인, 확인 위치> | <사유·대상·다음 확인 방법> |
```

### 5.2 검증 상태와 불확실성 기록

검증 상태는 자료·언어·검사 종류별로 `미확인`, `부분 확인`, `해당 범위 확인` 중 하나를 쓴다. ‘해당 범위 확인’에는 확인한 범위와 날짜가 있어야 한다. 하나의 언어·화면·검사가 통과했다고 다른 언어·실제 기기·원문 수집까지 완료로 올리지 않는다. `추가 탐색`은 포함 여부의 분류이며 검증 상태를 대신하지 않는다.

아래도 빈 양식이다. 새 주차를 시작할 때 각 검사 종류별 행을 만들고 상태와 미확인 사항을 갱신한다. 미확인 항목이 남아 있으면 결과 보고에 그 범위를 명시한다.

```text
| 주차·언어·과정 | 검사 종류 | 상태 | 확인일·근거 파일/URL | 확인한 범위 | 남은 불확실성·영향 | 다음 조치 |
|---|---|---|---|---|---|---|
| <주차, 언어, 기본/가족> | <자료 범위/원문 단위/누락·중복/부담 비교/파란 선·이동/공유·기록> | <미확인/부분 확인/해당 범위 확인> | <날짜와 근거> | <자료·경계·브라우저 폭/실제 기기 등> | <미확인 사항과 사용에 미치는 영향> | <다음 확인 방법> |
```

43주차는 조사 범위 안에서 **25개 문서, 1,117개 단위, 경전 217절, 연결 메시지/학습 글 9개**를 대조했다. 이는 모든 링크를 재귀적으로 따라간 인터넷 전체 자료에 대한 수치가 아니다.

| 일차 | 핵심 주제 | 기본 원문 단위 | 어린이·가족 원문 단위 |
|---|---|---:|---:|
| 1 | 선지자의 부름 | 172 | 6 |
| 2 | 정체성 발견 | 138 | 13 |
| 3 | 정체성의 적용 | 143 | 3 |
| 4 | 생수의 근원 | 160 | 0 (공유 원문·실물 활동) |
| 5 | 진실한 예배 | 180 | 3 |
| 6 | 집합에 참여하기 | 151 | 9 |
| 7 | 주님의 인도 | 133 | 6 |
| 합계 | | 1,077 | 40 |

기본 학습의 앱 자료 항목은 영상·돌아보기 활동을 포함해 67개이다. 이 항목 수를 1,117개 원문 단위와 혼동하지 않는다. 진행률은 사용자가 읽었다고 확인한 **앱 자료 항목 수**를 기준으로 계산한다. 가족 과정과 질문 참여는 따로 표시한다.

## 6. 앱 데이터로 옮기기

현재 구조:

- `src/data/cfm-2026-week-43.json`: 배정한 위치·자료·단위 목록. 시간이나 원문 전체를 싣지 않는다.
- `src/lib/cfm-study-plan.ts`: 범위, 공식 URL, 진행률 계산.
- `src/components/learning/study-reader.tsx`: 일차·과정·자료 전환과 공식 원문 읽기.
- `src/lib/study-material-progress.ts`: 계정별 자료 확인 기록. 질문 답변과 독립.

새 주차를 추가할 때 이 문서의 조사·대조 절차를 먼저 수행하고, 별도의 주차 데이터 파일을 만든다. 검증된 데이터가 없는 주차에 43주차 분량을 덮어쓰지 않는다. 주차 등록 함수·라우팅·테스트도 함께 확장한다.

자료별 필수 필드:

- `id`: 주차 안에서 안정적인 작업 ID. 재배분해도 의미가 같은 자료는 ID를 함부로 바꾸지 않는다.
- `path`, `sourceLang`: 공식 원문과 실제 제공 언어. 영어로만 제공되는 자료는 그 사실을 유지한다.
- `anchor`, `endAnchor`: 처음·끝 이동 위치.
- `sourceIds`, `units`: 조사·누락 대조를 위한 전체 단위.
- `selectedIds`: 화면에서 파란 선으로 표시할 본문·소제목·설명 단위. 주석 컨테이너나 페이지 전체 컨테이너를 그대로 선택하지 않는다.
- `noteLinks`: 각주와 인용 본문의 연결 위치.
- `kind`: 교재, 경전, 연결 말씀, 공유 원문, 영상, 활동의 성격.

## 7. 파란 선과 이동을 실제 브라우저에서 확인

공식 사이트의 `?id=문단ID1,문단ID2,…`와 `#이동위치`를 사용한다. 외부 iframe DOM을 앱이 수정해서 파란 선을 만든다고 가정하지 않는다.

- 일차를 고르면 그날 첫 자료의 지정 범위가 바로 열린다.
- ‘시작 보기’와 ‘끝 보기’는 **전체 selectedIds를 유지한 채** 이동 위치만 바꾼다.
- 하루의 마지막 본문과 다음 날 첫 본문 사이에 배정되지 않은 문단이 없는지 조사표와 대조한다.
- 시작·끝 문단, 소제목, 그림 설명에서 실제 파란 선을 확인한다. 그림 설명에만 선이 생겼는데 본문 전체가 선택됐다고 보고하지 않는다.
- 공식 상단 도구막대가 시작 문장을 가리지 않는지 확인한다. 원문 주변 문맥이 조금 보이는 것과 배정 범위가 틀리는 것은 구분한다.
- 각주와 영상은 별도 자료·바로가기로 접근 가능해야 한다.
- 어린이·가족 칩에서도 올바른 원문과 활동으로 이동해야 한다.
- 지원 언어마다 문단 ID가 실제 존재하는지 확인한다. 언어별 앵커가 다르거나 자료가 없으면 확인된 대체 자료 또는 공식 새 창 경로를 안내한다.
- 현재 43주차 구현은 임의 생성 문단 ID(`p_…`)가 있는 자료를 조사한 원문 언어로 유지하고 안내한다. 영어 전용 자료는 영어로 연다. 지원 언어로 URL을 만드는 자동 검사와, 각 번역의 모든 문단 경계를 실제 대조하는 작업은 다르다. 네 언어의 모든 경계 검증이 끝났다고 표시하지 않는다.
- iframe 표시가 막히면 항상 보이는 ‘원본·개인 주석’ 링크를 사용한다. 교회 계정 로그인·주석 저장이 iframe에서 항상 가능하다고 약속하지 않는다.

- 질문 링크로 들어온 손님이 질문을 읽고 이름 없이 답할 수 있는지 확인한다. 작성 중 초안과 개인 기록이 공개 모음에 섞이면 안 된다.
- 배분 변경 시 원문 변경 여부, 이전/이후 단위 배정, 이유, 실행한 검사와 남은 불확실성을 기록한다.
- 본문이 바뀌거나 자료 ID가 달라지면 기존 완료 기록을 새 자료에 자동 적용하지 않는다. 데이터 버전과 기록 이관 방침을 먼저 정한다.
- 운영 DB 마이그레이션·배포는 별도 절차이다. 배분 데이터나 로컬 브랜치 작업만으로 운영 DB를 수정하지 않는다.
