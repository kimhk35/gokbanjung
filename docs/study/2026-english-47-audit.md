# 47주차 영어 원문 위치 대조

확인일: 2026-11-15. 대상: [기존 47주차 선언 범위](2026-week-47-plan.md)의 52개 자료·107개 학습 항목. 배분 날짜·과정·항목 ID·한국어 원문 소유 단위·진행률은 바꾸지 않고 영어판의 실제 위치만 별도 등록한다.

## 결과와 범위 근거

- 영어 응답 **52/52개**, 기존 학습 항목 **107/107개**를 지원한다. 실제 수집 HTML의 `<html lang="en">`와 해시를 검사했다. 자료/범위 미확인으로 빠지는 영어 항목은 없다.
- 영어 선언 범위는 **1,521개 단위: 본문/제목/그림 설명 968개, 각주 553개**이다. 영어 단위 수가 한국어와 달라도 기존 학습 항목 수와 진도 분모를 바꾸지 않는다. 모든 원문 본문은 무시되는 캐시에만 보관한다.
- 주간 14장의 **223절**을 영어판에서 독립된 장별 절 수로 대조했다. 추가 지정 성구도 기존 배분의 논리 절 번호 집합과 정확히 일치한다. 문단 ID가 같다는 이유로 절을 추정하지 않는다. 이번 47주차에는 한국어에서 복수 절이 한 문단에 합쳐진 사례가 없지만, 생성기는 한 문단의 `verseNumbers` 전체를 읽어 대응한다.
- 영어 범위 기대값은 변환 결과를 합쳐 역산하지 않는다. 원래 자료 목록의 **전체 글/주간 장 전체/명시 절 범위**에 따라 영어 원문 캐시에서 기대 본문·각주 집합을 먼저 산출하고, 그 집합과 실제 변환의 소유 집합이 일치하는지 검사한다. 자료별 `scopeEvidence`에 원래 선언 범위·지정 절·영어 기대 ID를 기록했다.
- 교재·도움말·어린이 목록·교사 안내·월간 글처럼 여러 항목으로 나눈 문서는 원래 본문 순서를 영어 본문 전체 순서와 비교한다. 아래의 검증된 ID 치환 외에는 순서가 일치한다. 단순히 영어 URL에 한국어 랜덤 ID를 복사하는 방식이 아니다.
- 각주 번호는 한국어에서 가져오지 않는다. 영어 각주의 실제 `noteOwners`를 읽어, 영어 인용 본문을 소유한 가장 앞 항목에 한 번씩 연결한다. 지정 절 밖의 각주는 영어 범위에 끼워 넣지 않는다.

[영어 위치 JSON](../../src/data/cfm-2026-week-47-english.json)의 각 항목에는 기존 `path/sourceLang/anchor/endAnchor/selectedIds`를 복사한 `original` 지문이 있다. 나중에 항목 ID가 재사용되거나 배분 위치가 바뀌면 런타임이 오래된 영어 연결을 거부할 수 있다. 영어 `label`과 기존 안내문 전체의 영어 `readingNote`를 포함했다.

| 소아레스 어린이 글, `w47-t014`; 성신 색칠 글, `w47-t101` | 영어에 서지정보 `reference1` 한 단위씩 추가 | 원문 감사에는 소유 메타데이터로 보존. 파란 본문 선택에서 서지정보를 제외하는 기존 규칙 유지 |

「Enemy Territory」 영어판도 제목·소개 2단위와3:38 플레이어다. 「Teach by the Spirit」 영어판은 한국어와 같은 소제목 구조이며, 명시 읽기 지시의 Matthew4:1–11/John11:25–27 연결도 유지했다. 교재·어린이·교사 글의 본문 성구 장 링크는 언어 간 일치했고, 위 Bible Dictionary 차이는 별도로 공개했다.

## 검증과 한계

| 검사 | 결과 |
|---|---|
| 실제 응답 언어/해시 | 52개 모두 `en`, 수집 메타데이터와 HTML 해시 일치 |
| 원래 배분 보존 | 기존 JSON/단위 목록은 편집하지 않음. 107개 기존 항목의 원래 위치 지문 포함 |
| 선언 범위 대조 | 원래 전체 글/절 범위에서 산출한 영어 기대 본문·각주 집합과 1,521개 소유 단위 일치, 누락0/중복0/범위 밖0 |
| 주간 성구 | 14장223절, 장별 기대 절 수와 실제 영어 절 집합 일치 |
| 파란 범위 | 실제 영어 DOM에 모든 selectedId 존재. 선택 subtree가 다른 항목의 범위를 포함하거나 다른 항목과 겹치는 경우0 |
| 각주 | 영어 실제 인용 소유자 기반553개 단위 소유. `noteLinks.owner`는 그 항목의 영어 선택 본문 안에 있음 |
| 분할 글/랜덤 ID | 다중 항목 자료의 전체 병렬 본문 순서 검증, 위 언어별 ID 치환 명시 |
| 사용자 안내 | 영어 label107개, 기존 한국어 안내31개 영어로 대응. 영어판 교재의 사전 차이 안내1개 추가 |

이 검사는 공식 HTML과 변환 데이터/DOM 경계를 대조한 결과다. 교회 원문이 나중에 바뀌는 경우, 영상 자막/음성·PDF 내부·그림 속 글씨, 실제 휴대전화 스크롤/초안/공개 공유 동작까지 검증했다는 뜻은 아니다. 영상·PDF가 포함된 기존 선언 범위와 감사 한계는 [47주차 원래 계획](2026-week-47-plan.md)을 유지한다. 런타임 언어 선택/리더 표시의 테스트와 브라우저 검증은 통합 작업에서 별도로 수행한다.

재생성은 공식 영어 캐시가 필요하다.

```powershell
python scripts/study/audit-sources.py docs/study/2026-english-47-sources.json test-results/english47
python scripts/study/build-english-47.py
```

원문과 원래 배분이 바뀌면 위의 범위·문맥 대조를 다시 해야 한다. 새 데이터의 크기나 일치하는 ID 개수만으로 영어 대응을 검증 완료 처리하지 않는다.
