## 실제 차이가 있는 위치

| 자료 | 확인한 차이와 적용 |
|---|---|
| 주간 교재 | 도움말 링크 5개의 ID가 다르다. 제목·질문·연결 문서로 대조한 명시적 매핑을 사용한다. `p_h066E → p_zPEti`, `p_jYLoa → p_iImft`, `p_opNyv → p_mgM61`, `p_mJlX6 → p_mPtvc`, `p_a8DzN → p_cNrs4`. |
| 크리스토퍼슨 「너는 돌이킨 후에」 | 한국어의 문단 24개가 영어에서는 18개다. 연구와 기도를 다루는 첫 작업은 영어 `title1–p9`, 봉사와 보호를 다루는 다음 작업은 `p10–p16`이다. 한국어의 `p14`·`p15`를 영어에 그대로 대입하지 않는다. |
| 예레미야 32장 | 한국어 `p3`은 3~5절이 합쳐져 있다. 영어의 `p3`, `p4`, `p5`를 모두 포함한다. |
| 예레미야 33장 | 한국어 `p10`은 10~11절이다. 영어의 `p10`, `p11`을 모두 포함한다. |
| 「니파이의 용기」 | 영어 노래 번호는 120이며, 한국어의 저작권·복사 허가 문단 두 개가 영어에서는 하나다. 노래 전체와 끝의 참조 성구를 포함한다. |
| 「불 속에서도 안전했어요」 | 한국어의 QR 안내 `p_eQ4B5`는 영어에 없지만 이야기와 마지막 경전 이야기 안내는 대응한다. 영어의 이야기 10개 단위를 모두 포함한다. |
| 영어판 각주 | 한국어 각주 ID를 재사용하지 않는다. 실제 영어 각주와 그 영어 본문 소유 위치를 연결하며, 여러 곳에서 참조되는 각주 본문은 한 작업에만 배정한다. |

나뉘어 있는 교재, 경전 도움말, 어린이 자료 목록, 베드나·쿡·앤더슨 말씀 및 교사 자료는 소제목·의미·인용 성구·경계 문단을 대조했다. ID가 우연히 같다는 이유로 승인하지 않았다. 원래부터 한 작업에 전체가 배정된 문서는 같은 공식 경로의 영어 제목·내용과 시작·끝을 확인하고 영어 문서 전체를 유지했다. 이미 영어였던 밸라드 말씀과 두 노래는 모든 본문 단위의 ID·텍스트 해시가 기존 자료와 일치한다.
