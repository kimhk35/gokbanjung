# 2026년 47주차 7일 학습 배분

기준일: 2026-11-15. 적용 주간: **2026년 11월 16~22일**, 호세아 1~6장; 10~14장; 요엘.

## 확정 범위와 읽기 방식

- **52개 자료, 1,124개 원문 단위, 107개 항목**. 본문·제목·그림 설명·각주는 실제 공식 HTML의 ID와 해시로 기록하고 앱에는 원문을 복제하지 않는다. 원문 단위 1,124개는 화면 줄 수가 아니다.
- 주간 제목의 **14장, 223절**을 모두 기본 과정에 한 번씩 배정한다. 별도 지정 성구까지 합하면 기본 292절, 가족의 새 성구 3절이다. 각주 156개 단위를 포함한다. 절과 각주는 이미 글자 수에 들어 있으므로 추가 분량처럼 합산하지 않는다.
- 기본 72항목/893단위, 가족 35항목/231단위이다. 가족의 같은 호세아·요엘 성구는 `readingNote`와 `relatedTaskIds`로 기본 과정의 원래 항목에 연결한다. 새 필수 성구나 중복 파란 범위를 만들지 않으며 가족 과정을 해야만 기본 과정이 완료되는 구조도 아니다.
- 교재·보조자료의 **명시 읽기 안내 30묶음**에서 안내 다음 항목이 바로 해당 성구·말씀·찬송·영상이다. 여러 성구를 비교하는 지시는 모두 같은 날·과정의 연속 묶음으로 마친다. 개요·제목·인용은 모두 별도 재독 지시로 취급하지 않는다.
- 이미 읽은 자료를 다시 해설하거나 가족 활동에서 쓰는 곳은 원래 항목으로 연결하고 이유를 짧게 표시한다. [읽기 연결표](2026-week-47-reading-chains.csv)는 새 대상의 바로 이어짐과 재참조/이어읽기 예외를 별도로 기록한다.

범위 근거는 [자료 목록](2026-week-47-sources.json), 소유 일차·과정·항목과 해시는 [전체 단위 목록](2026-week-47-source-inventory.csv), 포함하지 않은 참조의 이유는 [링크 결정표](2026-week-47-source-links.csv)에 있다. `a[href]` 외에 작동하지 않는 `span[data-legacy-href]`도 분류했다. 영상·음악·그림·PDF는 [별도 매체 목록](2026-week-47-media.csv)에 남긴다.

직접 지정된 연결 말씀/학습 글은 본문·각주 전체를 포함한다. 보조자료의 모든 근거 인용이나 각주의 연결 문서까지 재귀적으로 확장하지 않는다. 예외적으로 「영으로 가르친다」의 마태복음 4:1~11과 요한복음 11:25~27은 본문에 직접 읽고 살펴보라는 지시가 있어 추가했다. 같은 글의 ‘참조 성구’ 목록은 별도 읽기 지시가 없는 추가 탐색이다.

## 언어·매체와 확인 한계

- 50개 자료는 한국어, 2개는 영어로 위치를 확인했다. 모든 항목을 확인한 언어에 잠가 다른 언어의 같은 ID가 같은 범위라는 보장을 하지 않는다.
- 「고요하고 작은 음성」은 어린이 자료의 실제 `data-legacy-href`가 노래책을 가리킨다. 한국어 요청은 본문이 없는 목차로 귀결됐고 영어 11개 가사/제목 단위를 확인했다. 색칠 그림은 다음 항목 「나는 성신을 느껴요」에 속한다.
- 「Weekly Scripture Fun」 한국어 직접 경로는 2026-11-15 HTTP404였다. 영어 전체 63단위를 포함했다. 반면 「성신」 노래는 영어 링크가 있어도 한국어 가사가 실제 제공돼 한국어 14단위를 사용했다.
- 베드나 토론은 한국어 페이지의 제목·저자·날짜 5단위와 전체 플레이어 61:29이다. 한국어 전문은 제공되지 않는다. 교재 p16~18의 인용문은 별도로 빠짐없이 보존하고 바로 다음 영상 항목에 제공형태와 길이를 알린다.
- 「적진」은 한국어 소개문과 전체 플레이어3:38이다. 어린이 자료의 「Time to Seek the Lord | Hosea10」은 p_rRJB3 바로 아래 삽입된 공식 전체 영상0:35이며 별도 본문 ID/전문이 없다. 해당 위치 자체를 영상 항목으로 배정한다.
- 그림의 글씨·PDF/활동지 내부, 영상 자막 전문·음원은 독립 전사 대조하지 않았다. 공식 원문/매체 링크와 배정 위치를 목록에 보존했고 텍스트 단위 감사와 구분한다. 일반 말씀의 영상은 글 전문의 다른 제공형태로 중복 필수 영상 시간을 더하지 않는다. 「영으로 가르친다」 상단의 학습 영상은 4:17이며 3일차 첫 부분과 함께 배정하고 별도 영상 부담으로 센다. 매체 CSV에는 같은 「적진」 영상의 교재 삽입과 독립 플레이어가 모두 나오므로 행의 길이를 단순 합산하지 않고 해당 항목의 원 소유자 기준으로 한 번만 센다.
- 이 감사의 실제 파란 범위 검사란 공식 HTML의 선택 ID 존재·선택 범위/소유 범위 일치·경로/언어/ID 중복 없음이다. 브라우저 스크롤/파란선 표시, 실제 휴대전화, 진도·초안·공개 공유 회귀는 통합 담당자가 별도로 확인한다.
