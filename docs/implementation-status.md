## 배포 전 필요한 사용자 지정

1. Supabase 프로젝트: 현재 확인된 조직은 **Ajou University**. 이 조직에 새 프로젝트를 만들지, 지정된 프로젝트를 사용할지 결정해야 합니다. 새 프로젝트 생성 시 비용 확인 절차가 필요할 수 있습니다.
2. Vercel 연결 또는 배포 가능한 해당 계정의 프로젝트 연결.
3. OpenAI API 키는 배포 환경변수로 등록. 채팅이나 저장소에 평문으로 적지 않습니다.
4. 최초 관리자 계정은 실제 Supabase 인증 계정 생성/이메일 인증 후 별도 초기화 스크립트로 지정.
