# 리워드 운영 원칙

일간 새싹 → 주간 책갈피 → 월간 21일 꾸준한 배움 배지.

- 일간 완료는 묵상의 ‘마음에 남은 것’과 ‘오늘의 실천’을 입력한 경우 인정한다. 답변의 신앙적 내용이나 수준을 채점하지 않는다.
- 주간 책갈피는 해당 주 7개 일간 공과를 모두 마치면 1회 지급한다.
- 월간 출석은 공과의 계획 날짜가 아니라 서버가 기록한 실제 완료 날짜를 한국 시간으로 계산한다.
- 하루 여러 공과 완료는 하루 출석이다. 월간 달성은 연속 21일이 아니라 해당 달의 서로 다른 21일이다.
- 월말에 목표를 달성하지 못해도 이전에 받은 리워드를 회수하지 않는다.
- 월간 기념 카드는 이름 입력 없이 내려받을 수 있으며 개인 기록이다.
- 공개 순위표, 신앙/영성/도덕성 점수, 현금 교환, 자동 상품 발송은 없다.
- 중복 요청은 DB의 owner/kind/period 유일 제약으로 막는다. 지급 트리거는 소유자 검증 후 실행되고 클라이언트는 직접 보상 기록을 쓸 수 없다.
- 감사용 저장값: kind, period, earned_at. 개인 묵상 본문을 보상 테이블에 복제하지 않는다.
