# 최신 통합판 검증 결과

2026-09-14. 운영 환경 검증과 로컬 소스 검증을 구분합니다.

## 통과

- `npm test`: 9개 테스트 통과. 52주 이중언어·추천 질문·경전 주소·모든 주차 퀴즈 범위·80% 경계·서버 한국 날짜·기록 관리 권한·DB RLS·기존 리워드 중복 방지.
- `node --import tsx scripts/release-smoke.mts`: 닉네임이 같은 사용자 분리, 관리자만 로그인 승인, 게스트 기록 보존, 승인 전 기록 조회 차단, 일/주/월 서버 채점, 동시 제출 보상 1회, 정답표 접근 차단, 회원 정지.
- `node --import tsx scripts/service-smoke.mts`: 교사 승인·정지, 토론, 활동지 버전 충돌·제출본 보존, 교사 피드백, 관리자 개인 묵상 접근 차단.
- `npm run build`: Next.js 프로덕션 빌드 및 TypeScript 검사 통과.
- `node --check`: DB 업데이트·초기 관리자 설정·비밀값 입력 스크립트 문법 확인.
- 공식 이사야 1장 HTML에서 실제 p1~p31 구조 확인. 교리와 성약 공식 주소의 dc-testament 경로 확인.

## 남은 운영 확인

- 브라우저 검사는 자동화 도구 데몬 시작 실패, 브라우저 다운로드 실패, 로컬 서버 네트워크 인터페이스 제한으로 완료하지 못함. 화면 캡처·실제 모바일 조작 완료를 주장하지 않음.
- 실제 OpenAI 키를 이용한 새 퀴즈·묵상 요약 호출은 미실행. 결제·권한·모델 응답은 운영 환경에서 확인 필요. 통합 테스트의 퀴즈 데이터는 테스트용 fixture 사용.
- 실제 Supabase 이메일 인증·실제 관리자 로그인·Windows 실행 파일은 사용자의 계정/기기에서 확인 필요. 초기 관리자 비밀번호는 ZIP에 포함하지 않음.
- ESLint에는 상태 동기화 패턴 관련 규칙 오류와 기존 경고가 남아 있음. 빌드 성공을 린트 통과로 표시하지 않음.
- 기존 지시서의 선택적 고급 기능 전체 완료를 의미하지 않음. 초기 이력은 implementation-status.md 참조.

## 적용 주의

이 통합판은 새 계정 승인/퀴즈 테이블을 사용하므로 05번 DB 업데이트 후 04번으로 배포해야 합니다. 기존 DB에서는 seed.sql을 다시 실행하지 않습니다. 새 테이블은 RLS를 켜고 정답표·계정 신청은 브라우저 역할에 공개하지 않습니다.
