## 수업 구성

관리자 또는 승인된 교사로 로그인 → 상단 `수업 구성` → 주차 선택.

1. `질문 · 활동 추가`로 항목을 추가합니다.
2. 시작 화면 / 질문 / 경전 읽기 / 활동 / 설명 / 이미지 / 생각벽 중 유형을 선택합니다.
3. 제목과 내용을 입력합니다. 캡처 이미지는 항목 안에서 Ctrl+V로 붙이거나 파일을 선택합니다.
4. 위로·아래로 이동하거나 `수업에 표시`를 꺼 순서와 표시 여부를 조정합니다.
5. 수업 화면의 배경과 글자 크기를 고르고 `수업 구성 저장`을 누릅니다.
6. `수업 화면 열기`로 프로젝터용 화면을 엽니다. 편집 화면의 `이 화면 보여주기`를 누르면 최대 5초 이내 해당 항목으로 이동합니다.
7. 질문 항목의 `토론방에 질문 던지기`로 토론방에도 질문을 게시할 수 있습니다.

수업 구성은 주차별로 저장됩니다. 구성 항목이 비어 있으면 기존 기본 수업 화면을 사용합니다. 항목을 전부 숨겼다면 표시할 항목이 없다는 안내를 보여줍니다.

### PowerPoint와 이미지

- `.pptx` 20MB 이하, 수업 전체 40개 항목까지 가져옵니다.
- 슬라이드 순서대로 텍스트와 지원 이미지(PNG/JPG/WebP/GIF)를 추출합니다. 한 슬라이드의 추가 이미지는 별도 이미지 항목으로 가져옵니다.
- 원본의 배치·도형·동영상·애니메이션은 그대로 재현하지 않습니다. 가져온 항목을 편집하여 사용하세요.
- 구형 `.ppt`는 PowerPoint에서 `.pptx`로 저장한 뒤 넣어 주세요.
- 개별 이미지는 12MB 이하로 넣을 수 있고 자동으로 축소됩니다. 전체 저장 요청은 3.5MB 미만으로 제한됩니다. 이미지가 많다면 나누거나 줄여 주세요.

## 공지 관리

관리자 화면과 교사 화면의 `공지 관리` 탭에서 작성·수정·삭제합니다. 한 언어만 작성하면 게시 시 다른 언어를 AI로 번역합니다. 양쪽을 직접 입력하면 API 호출 없이 저장합니다. 수정 시 번역 버튼으로 다른 언어도 갱신할 수 있습니다.

새 공지와 내용이 수정된 공지는 학습 화면에서 팝업으로 표시합니다. 최초 접속, 화면으로 돌아올 때, 접속 중 60초 간격으로 새 공지를 확인합니다. `확인했어요`를 누른 공지 버전은 해당 계정·기기에서 다시 열리지 않습니다. 홈에서는 최근 공지를 다시 읽을 수 있습니다. 편집·관리 화면과 발표 화면에서는 팝업을 띄우지 않습니다.

## AI 점검

관리자 → `AI 질문 생성` → `실제 AI 연결 확인`을 누르면 **현재 운영 배포의 키와 모델로 실제 응답**을 요청합니다. 소량의 API 비용이 발생합니다.

키는 `OPENAI_API_KEY`를 우선하며, 없으면 기존 `OPEN_API_KEY`를 사용합니다. `OPENAI_MODEL` 값 앞뒤 공백을 제거하고, 비어 있으면 기존 기본 모델을 사용합니다.

인증 실패·결제/사용 한도·모델 접근 권한·요청 제한·연결 실패·시간 초과를 구분하여 알려줍니다. 오류 분류는 [OpenAI 공식 오류 안내](https://developers.openai.com/api/docs/guides/error-codes)를 참고했습니다.

### 검증 범위

- AI 질문, 활동지, 오늘의 묵상 정리, 주간 요약, 수업 요약, 교재 분석, 번역의 생성·검증·저장 흐름.
- 일간 3 / 주간 10 / 월간 20문항 퀴즈 생성 및 제출 전 정답 비공개.
- 관리자/교사 공지 관리, 일반 참여자·승인 전 교사의 수정 차단, 과정별 분리.
- 수업 구성 저장·권한·화면 선택·버전 확인.
- 브라우저에서 한국어/EN 전환, PC/모바일 가로 넘침, 다크모드 글자색, 공지 팝업 확인 상태 유지.
- 브라우저에서 이미지 선택·저장 데이터·발표 화면 표시, PPTX 가져오기·원본 슬라이드 순서.

AI 제공자 응답은 테스트 데이터로 대체했습니다. 브라우저의 관리자 수업 편집 검증에서도 테스트용 네트워크 응답을 사용했고, 서버 권한·저장은 별도 로컬 DB 통합 테스트로 검증했습니다. 실제 운영 키의 결제 상태·모델 사용 권한 및 운영 환경의 전체 AI 호출은 직접 확인하지 못했습니다.

## 추가 수정: AI 질문 오류 · 가입 · 학습 진행

- AI 결과가 JSON 문자열로 중복 저장되어 한 글자씩 표시되던 문제를 수정했습니다. 기존 문자열 형태의 질문도 읽을 때 복원합니다. 새 저장은 JSON 객체를 유지합니다.
- 수업 구성의 AI 추천 질문은 결과를 검증한 후 화면에 추가합니다. 잘못된 응답이면 기존 수업을 유지하고 재시도를 안내합니다.
- 교사 AI 결과는 질문 번호 목록, 활동지 문장, 공개 생각 요약으로 표시합니다.
- 퀴즈 제목을 카드 안에 배치하고 긴 질문·보기 및 모든 글자 크기에서 줄바꿈을 적용했습니다.
- 수업 구성 → **수업 장수 (1~40장)** → **장수 적용 · 저장**으로 표시할 장수를 변경합니다. 줄인 장은 숨김으로 보관하며 다시 늘리면 먼저 복원합니다.
- 이미지 카드와 수업 화면에 **십자가가 없는 종교적 배경 20종**을 추가했습니다. 펼친 경전, 성전의 새벽, 감람나무 정원, 갈릴리의 고요, 광야의 길, 산 위의 빛, 생수의 흐름, 등불, 추수의 들판, 백합, 베들레헴의 별, 성스러운 숲, 겨자씨, 부활의 아침, 목자의 초원, 포도원, 기도, 무지개, 하늘, 비둘기입니다. 앱에 포함한 벡터 일러스트로 별도 AI 비용이 없습니다.
- **로그인 · 승인 신청**의 가입란에는 이름·이메일·비밀번호만 입력합니다. 닉네임 사전 입력은 필요 없습니다. 기존 게스트 기록은 같은 브라우저의 학습 ID에 연결합니다. 이름은 학습 표시 이름으로 사용합니다.
- 가입/재설정 비밀번호는 10~128자이며 영문·숫자·기호 혼합과 다른 사이트와 다른 비밀번호를 안내합니다.
- 로그인 화면의 **비밀번호를 잊으셨나요?**에서 재설정 메일을 요청하고 메일 링크에서 새 비밀번호를 저장합니다.
- 관리자 → **로그인 승인** → **계정 비밀번호 관리**에서 사용자를 선택해 재설정 메일을 보내거나 새 비밀번호로 초기화합니다. 권한·승인 상태·학습 기록은 바뀌지 않습니다.
- 나의 신앙 여정: 완료 학습일·묵상 기록·저장 말씀, 주간 완료율, 요일별 완료, 월별 학습량과 날짜 달력. 학습 일정에 연결된 완료 기록을 집계하며, 실제 접속 시각을 출석으로 추정하지 않습니다.
- 일별 수업 오른쪽 메뉴의 01~07을 실제 날짜로 변경하고 일요일은 빨간색으로 표시합니다.

### 이메일 기능 최초 설정 (Supabase)

Supabase 프로젝트 → Authentication → URL Configuration:

1. Site URL: `https://gokbanjeong-gospel-class.vercel.app`
2. Redirect URLs에 다음 두 주소를 허용합니다.
   - `https://gokbanjeong-gospel-class.vercel.app/auth/confirm`
   - `https://gokbanjeong-gospel-class.vercel.app/auth/reset-password`
3. Authentication의 이메일 제공자에서 이메일 가입을 활성화합니다. 이메일 인증 설정은 유지해도 됩니다.
4. 실제 사용자에게 메일을 보내려면 Email/SMTP 설정과 발송 한도를 확인합니다. 기본 발송 서비스에서 수신자가 제한된다면 사용자 지정 SMTP를 설정해야 합니다.

가입 인증은 신청한 브라우저에서 링크를 여세요. 비밀번호 재설정은 메일의 보안 링크로 계정을 확인하고 새 비밀번호 저장 후 다시 로그인합니다. 이 작업 환경에서는 실제 수신자에게 메일을 보내지 않았고, 운영 Supabase 설정을 변경하지 않았습니다. 메일/인증 API 검증에는 테스트 응답을 사용했습니다.

참고: [Supabase 비밀번호 재설정](https://supabase.com/docs/reference/javascript/auth-resetpasswordforemail), [관리자 비밀번호 변경](https://supabase.com/docs/reference/javascript/auth-admin-updateuserbyid), [Postgres JSON 데이터](https://supabase.com/docs/guides/database/json), [OpenAI JSON 응답 검증](https://developers.openai.com/api/docs/guides/structured-outputs).

이번 추가 수정도 DB 구조 변경은 없습니다. 기존 폴더에 전체 덮어쓰기 후 04번 배포 파일을 실행하세요. API 키를 새로 만들 필요는 없습니다. 외부 운영 인증에 접근할 수 없어 자동 운영 배포는 완료하지 못했습니다.

### 이번 수정의 검증 범위

15개 자동 테스트를 통과했습니다. 실제 Postgres.js JSON 직렬화 함수와 로컬 PostgreSQL 엔진에서 중복 문자열 문제를 재현하고 수정 동작을 확인했습니다. AI API·이메일 제공자 응답은 테스트 데이터로 대체했습니다. 브라우저에서는 관리자·교사 질문 목록 복원, 추천 질문 추가/실패/재시도, 수업 10→3→10장 변경과 내용 보존, 20종 배경 선택/PNG 저장, 가입 세 필드, 재설정 메일/관리자 초기화 화면, 진행 4/7=57%, 실제 날짜와 일요일 표시를 확인했습니다. 퀴즈 카드 범위는 모바일·데스크톱, 밝은/어두운 모드, 글자 크기 3종에서 검증했습니다.
